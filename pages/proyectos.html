Mis trabajos y proyectos web

Estos son algunos de los trabajos que he realizado:

Turnos y Tienda Oh my Dogggie

Plataforma web desarrollada para una veterinaria que permite a los usuarios solicitar turnos online y comprar alimento para perros de forma rápida y segura. Incluye gestión de productos, reservas de turnos, autenticación de usuarios y una interfaz intuitiva para mejorar la experiencia del cliente.

Sistema de Autenticación Full Stack

Aplicación Full Stack desarrollada con React, Node.js, Express y MySQL que implementa un sistema completo de autenticación y autorización de usuarios. Incluye registro, inicio y cierre de sesión, autenticación mediante JWT, protección de rutas, cifrado de contraseñas con bcrypt y gestión segura de sesiones para garantizar el acceso controlado a la aplicación.

Sistema de Subida de Archivos (PERN Stack)

Un sistema de subida de archivos desarrollado con la pila PERN (PostgreSQL, Express, React, Node.js) que permite a los usuarios cargar y gestionar sus archivos de manera eficiente, para postularse Flashbox Logística-Rapipago.
